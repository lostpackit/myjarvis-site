MYJARVIS

Privacy Policy

Effective date: September 17, 2026 · Last updated: September 17, 2026

Overview

Myjarvis is a personal productivity and executive-function assistant operated for one account owner. This policy explains how Myjarvis handles information when the owner connects Google services.

Google data accessed

With the owner’s explicit authorisation, Myjarvis may access the minimum Google data needed for an approved workflow, including:

  • Gmail message headers, subjects, snippets, message bodies, labels, and threads for inbox monitoring, reports, and approved replies.
  • Calendar event details when the owner requests scheduling or calendar review.
  • Drive, Docs, or Sheets content only when the owner requests a related file or document workflow.

How data is used

Google data is used only to provide the requested personal-assistant functions: monitoring specified conversations, preparing summaries and reports, drafting or sending messages when approved, and carrying out approved productivity tasks. Myjarvis does not sell Google data, use it for advertising, or use it to build advertising profiles.

For Gmail, Myjarvis uses message metadata and message content only when needed to find relevant conversations, prepare a requested summary, draft a response, or send a message that the owner has authorised. For Calendar, Drive, Docs, and Sheets, access is limited to the specific workflow requested by the owner. Myjarvis does not use Google data for unrelated artificial-intelligence model training.

Google API Services User Data Policy

Myjarvis’s use and transfer of information received from Google APIs complies with the Google API Services User Data Policy, including its Limited Use requirements. Google user data is used only to provide or improve the user-facing features described above, is not transferred to third parties for advertising or creditworthiness purposes, and is not sold.

Sharing and storage

Google data is not sold or shared with third parties except where necessary to operate an explicitly requested integration or where required by law. Myjarvis does not allow unauthorised people to access the connected mailbox. Authorisation tokens and workflow data are stored on the owner’s private server with access controls. Reports may be delivered to the owner through configured communication channels.

Data is retained only for as long as needed for the requested workflow and its report history. The owner may request deletion of locally stored Google-derived data at any time using the contact address below.

User control and deletion

The owner can revoke Myjarvis’s Google access at any time from Google Account third-party connections. The owner may also request deletion of locally stored workflow data by contacting the address below. Revoking access does not delete records retained by Google; those must be managed in the owner’s Google Account.

Security

Reasonable technical and organisational safeguards are used to protect credentials and stored workflow data. No internet-connected service can guarantee absolute security.
